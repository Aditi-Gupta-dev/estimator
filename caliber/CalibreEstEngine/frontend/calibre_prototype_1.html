Estimation methodology

Calibre supports four core techniques. Each has different data requirements and appropriate use cases.

All methods
ROM
Detailed
Analogous
Parametric
ROM

Rough order of magnitude

Used at early stages with limited scope definition. Accuracy range: −25% to +75%. Best for feasibility and go/no-go decisions.

BTM

Detailed bottom-up

Work package level estimation with full scope breakdown. Accuracy: ±5–10%. Requires a WBS and unit rates from SMEs.

ANA

Analogous

Uses actuals from similar past projects. Accuracy: ±10–20%. Requires strong historical data and documented similarity criteria.

PRM

Parametric

Statistical models using cost/schedule drivers. Accuracy: ±10–15%. Calibre's engine auto-runs parametric estimates when sufficient data exists.

Glossary

Key terms used across Calibre's estimation workflows.

WBS

Work Breakdown Structure

Hierarchical decomposition of project scope into estimable work packages.

ROM

Rough order of magnitude

A high-level estimate (−25% to +75% range) for early-stage feasibility decisions.

BL

Baseline

An approved, locked estimate used as the reference for variance analysis.

UR

Unit rate

Cost or effort per unit of output, maintained by SMEs and used in bottom-up estimation.

SLM

Small language model

A locally-run AI model used to process sensitive enterprise data without cloud exposure.

COE

Centre of excellence

Governance body responsible for estimation standards, calibration, and policy.

TCO

Total cost of ownership

Full lifecycle cost including acquisition, operation, maintenance, and decommission.
